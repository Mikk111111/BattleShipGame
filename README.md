# Battleship Game

![Battleship](app/src/main/res/drawable/background.png)

---

## About

A classic Battleship game developed in Kotlin using Jetpack Compose for Android.

Features multiple difficulty levels, score tracking, persistent leaderboards, custom player names, and an AI opponent.

---

## Features

- Turn-based Battleship gameplay
- Easy, Normal and Hard difficulties
- Smart AI opponent
- Score system
- Local leaderboard
- Persistent player name
- Pixel-art graphics
- Responsive landscape game board

---

## Technologies

- Kotlin
- Jetpack Compose
- Android Studio
- SharedPreferences
